# 5.3 Architecture d'un réseau

!!! note "Cours"
    Un **réseau informatique** relie plusieurs machines pour qu'elles
    échangent des données. On distingue notamment :

    - le **réseau local** (LAN), à l'échelle d'un bâtiment,
    - **Internet**, le réseau mondial interconnectant des millions de
      réseaux.

    Chaque machine connectée possède une **adresse IP**, qui l'identifie sur
    le réseau.

!!! example "Adresse IPv4"
    Une adresse IPv4 s'écrit sous la forme de quatre nombres entre 0 et 255,
    séparés par des points : `192.168.1.10`.

!!! tip "Le rôle du routeur"
    Un **routeur** est l'équipement qui relie un réseau local à Internet et
    qui achemine les paquets de données vers la bonne destination.

## Activité

1. Trouver l'adresse IP de votre propre machine (commande `ipconfig` sous
   Windows, `ifconfig` ou `ip a` sous Linux/macOS).
2. Utiliser la commande `ping` pour tester la connexion à un serveur.

## Exercices

1. Combien d'adresses IPv4 différentes existe-t-il au total ? Pourquoi
   IPv6 a-t-il été créé ?

??? abstract "Correction"
    Une adresse IPv4 étant codée sur 32 bits, il existe $2^{32}$, soit
    environ 4,3 milliards d'adresses possibles. Ce nombre étant devenu
    insuffisant face à la croissance d'Internet, IPv6 (codé sur 128 bits) a
    été créé pour offrir un espace d'adressage bien plus vaste.
