# 5.2 Commandes UNIX

!!! note "Cours"
    Les systèmes de type **UNIX** (Linux, macOS...) proposent un **terminal**
    permettant de piloter l'ordinateur en ligne de commande.

    | Commande | Rôle |
    |----------|------|
    | `pwd` | Afficher le dossier courant |
    | `ls` | Lister le contenu d'un dossier |
    | `cd dossier` | Se déplacer dans un dossier |
    | `mkdir nom` | Créer un dossier |
    | `touch fichier` | Créer un fichier vide |
    | `rm fichier` | Supprimer un fichier |
    | `cat fichier` | Afficher le contenu d'un fichier |

!!! example "Arborescence"
    Le système de fichiers est organisé en **arbre**, avec une racine `/` :

    ```
    /
    ├── home/
    │   └── eleve/
    │       ├── documents/
    │       └── projets/
    └── etc/
    ```

!!! tip "Chemins relatifs et absolus"
    - Un chemin **absolu** commence par `/` (depuis la racine).
    - Un chemin **relatif** part du dossier courant (`./`, `../` pour
      remonter d'un niveau).

## Activité

1. Ouvrir un terminal et naviguer jusqu'à votre dossier personnel avec `cd`.
2. Créer un dossier `test`, s'y déplacer, créer un fichier, puis remonter
   d'un niveau avec `cd ..`.

## Exercices

1. Quelle commande permet de copier un fichier ? De le déplacer ?

??? abstract "Correction"
    `cp source destination` permet de copier un fichier, `mv source destination`
    permet de le déplacer (ou de le renommer si la destination est dans le
    même dossier).
