# 7.4 Algorithmes gloutons

!!! note "Cours"
    Un **algorithme glouton** construit une solution étape par étape, en
    faisant à chaque étape le choix qui semble **localement optimal**, sans
    revenir en arrière. Il ne garantit pas toujours la solution optimale,
    mais il est souvent simple et rapide.

!!! example "Rendu de monnaie"
    Pour rendre 67 centimes avec des pièces de 50, 20, 10, 5, 2 et 1
    centimes, l'algorithme glouton choisit à chaque étape la plus grande
    pièce possible :

    ```python
    def rendu_monnaie(montant, pieces):
        pieces = sorted(pieces, reverse=True)
        resultat = []
        for piece in pieces:
            while montant >= piece:
                resultat.append(piece)
                montant -= piece
        return resultat

    print(rendu_monnaie(67, [50, 20, 10, 5, 2, 1]))
    # [50, 10, 5, 2]
    ```

!!! warning "Attention : pas toujours optimal"
    Avec certains systèmes de pièces (par exemple 1, 3 et 4), l'algorithme
    glouton peut donner un résultat qui n'est **pas** optimal. Pour rendre
    6, le glouton choisirait `4 + 1 + 1` (3 pièces) au lieu de `3 + 3`
    (2 pièces).

## Exercices

1. Écrire un algorithme glouton qui, étant donné un sac à dos de capacité
   `C` et une liste d'objets `(valeur, poids)`, choisit les objets par
   ordre décroissant de rapport valeur/poids jusqu'à remplir le sac.

??? abstract "Correction"
    ```python
    def sac_a_dos_glouton(capacite, objets):
        objets = sorted(objets, key=lambda o: o[0] / o[1], reverse=True)
        resultat = []
        for valeur, poids in objets:
            if poids <= capacite:
                resultat.append((valeur, poids))
                capacite -= poids
        return resultat
    ```
