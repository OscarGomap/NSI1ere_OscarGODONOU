# 7.3 Tri par insertion

!!! note "Cours"
    Le **tri par insertion** construit la liste triée petit à petit : à
    chaque étape, on prend l'élément suivant et on l'insère à sa bonne place
    parmi les éléments déjà triés.

    C'est la méthode naturelle qu'on utilise souvent pour trier des cartes à
    jouer dans sa main.

!!! example "Implémentation"
    ```python
    def tri_insertion(liste):
        for i in range(1, len(liste)):
            valeur = liste[i]
            j = i - 1
            while j >= 0 and liste[j] > valeur:
                liste[j + 1] = liste[j]
                j -= 1
            liste[j + 1] = valeur
        return liste
    ```

!!! tip "Complexité"
    Dans le pire des cas (liste triée à l'envers), la complexité est en
    $O(n^2)$. Mais si la liste est presque triée, le tri par insertion est
    beaucoup plus rapide en pratique que le tri par sélection.

## Exercices

1. Combien de comparaisons le tri par insertion effectue-t-il sur une liste
   déjà triée de taille $n$ ?

??? abstract "Correction"
    Sur une liste déjà triée, chaque nouvel élément est comparé une seule
    fois à son prédécesseur (la condition `liste[j] > valeur` est
    immédiatement fausse) : il faut donc seulement $n-1$ comparaisons, soit
    une complexité en $O(n)$ dans ce cas particulier.
