# T7.1 Recherche par dichotomie

!!! note "Cours"
    La **recherche dichotomique** permet de trouver un élément dans une liste
    **triée** en divisant à chaque étape l'intervalle de recherche par deux.
    Sa complexité est en $O(\log_2 n)$, bien plus efficace qu'un parcours séquentiel.

!!! example "Exemple"
    ```python
    def recherche_dichotomique(liste, cible):
        debut, fin = 0, len(liste) - 1
        while debut <= fin:
            milieu = (debut + fin) // 2
            if liste[milieu] == cible:
                return milieu
            elif liste[milieu] < cible:
                debut = milieu + 1
            else:
                fin = milieu - 1
        return -1
    ```
