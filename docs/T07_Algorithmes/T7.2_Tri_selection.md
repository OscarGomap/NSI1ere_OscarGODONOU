# 7.2 Tri par sélection

!!! note "Cours"
    Le **tri par sélection** consiste, à chaque étape, à rechercher le plus
    petit élément restant et à le placer à sa position définitive.

!!! example "Principe"
    Pour trier `[5, 2, 8, 1]` :

    1. Le minimum de la liste est `1` → on l'échange avec le premier élément
       → `[1, 2, 8, 5]`
    2. Le minimum des éléments restants (`2, 8, 5`) est `2`, déjà bien placé
       → `[1, 2, 8, 5]`
    3. Le minimum de `8, 5` est `5` → on échange → `[1, 2, 5, 8]`

!!! example "Implémentation"
    ```python
    def tri_selection(liste):
        n = len(liste)
        for i in range(n):
            indice_min = i
            for j in range(i + 1, n):
                if liste[j] < liste[indice_min]:
                    indice_min = j
            liste[i], liste[indice_min] = liste[indice_min], liste[i]
        return liste
    ```

!!! tip "Complexité"
    Le tri par sélection effectue toujours environ $\dfrac{n^2}{2}$
    comparaisons : sa complexité est en $O(n^2)$, quel que soit l'état
    initial de la liste.
