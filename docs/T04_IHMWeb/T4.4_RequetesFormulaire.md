# 4.4 Formulaires, méthodes GET et POST

!!! note "Cours"
    Un **formulaire HTML** permet d'envoyer des données au serveur. Deux
    méthodes principales :

    - **GET** : les données sont ajoutées à l'URL (visibles, limitées en
      taille). Adaptée à une recherche, un filtre.
    - **POST** : les données sont envoyées dans le corps de la requête
      (non visibles dans l'URL). Adaptée à l'envoi d'un mot de passe, d'un
      formulaire de contact.

!!! example "Formulaire en GET"
    ```html
    <form action="/recherche" method="GET">
      <input type="text" name="q">
      <button type="submit">Rechercher</button>
    </form>
    ```

    Une recherche de "python" enverra vers `/recherche?q=python`.

!!! example "Formulaire en POST"
    ```html
    <form action="/connexion" method="POST">
      <input type="text" name="identifiant">
      <input type="password" name="mdp">
      <button type="submit">Se connecter</button>
    </form>
    ```

## Activité

1. Créer un formulaire GET avec un champ texte et observer l'URL générée
   après validation.
2. Expliquer pourquoi un formulaire de connexion ne doit jamais utiliser la
   méthode GET.

## Exercices

1. Citer deux différences essentielles entre GET et POST.

??? abstract "Correction"
    - GET affiche les paramètres dans l'URL (donc visibles et limités en
      taille), POST les transmet dans le corps de la requête (invisibles
      et sans limite pratique de taille).
    - GET est conçu pour des requêtes qui ne modifient pas l'état du
      serveur (idempotentes), POST pour des actions qui créent ou
      modifient des données.
