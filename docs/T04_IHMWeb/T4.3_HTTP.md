# 4.3 Protocole HTTP

!!! note "Cours"
    **HTTP** (HyperText Transfer Protocol) est le protocole utilisé pour
    échanger des données entre un **client** (navigateur) et un **serveur**
    web. Chaque échange se compose d'une **requête** et d'une **réponse**.

    Une requête HTTP contient :

    - une **méthode** (GET, POST, ...)
    - une **URL**
    - des **en-têtes** (headers)
    - éventuellement un **corps** (body)

    Une réponse contient un **code de statut** (200 OK, 404 Not Found, 500
    Internal Server Error...), des en-têtes et un corps.

!!! example "Codes de statut courants"
    | Code | Signification |
    |------|----------------|
    | 200 | OK |
    | 301 | Redirection permanente |
    | 404 | Page non trouvée |
    | 500 | Erreur serveur |

!!! tip "Observer les requêtes"
    Dans un navigateur, l'onglet **Réseau** des outils de développement
    (touche F12) permet de visualiser toutes les requêtes HTTP émises par
    une page.

## Activité

1. Ouvrir les outils de développement du navigateur, onglet Réseau, et
   observer les requêtes émises en chargeant une page web.
2. Identifier le code de statut de chaque requête.

## Exercices

1. Que signifie un code de statut commençant par 4 ? Par 5 ?

??? abstract "Correction"
    Un code commençant par **4** indique une erreur côté client (la requête
    est incorrecte ou la ressource n'existe pas). Un code commençant par
    **5** indique une erreur côté serveur (le serveur n'a pas pu traiter la
    requête correctement).
