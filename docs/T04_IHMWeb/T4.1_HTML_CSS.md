# T4.1 HTML & CSS

!!! note "Cours"
    **HTML** (HyperText Markup Language) décrit la structure d'une page web.
    **CSS** (Cascading Style Sheets) définit sa présentation (couleurs, mise en page...).

!!! example "Exemple"
    ```html
    <!DOCTYPE html>
    <html lang="fr">
      <head>
        <meta charset="UTF-8">
        <title>Ma page</title>
        <style>
          h1 { color: navy; }
        </style>
      </head>
      <body>
        <h1>Bonjour NSI !</h1>
        <p>Ceci est un paragraphe.</p>
      </body>
    </html>
    ```

## Activité

1. Créer une page HTML avec un titre, un paragraphe et une image.
2. Ajouter une feuille de style CSS pour modifier les couleurs et les polices.
