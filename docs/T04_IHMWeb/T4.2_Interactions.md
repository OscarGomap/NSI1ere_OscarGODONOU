# 4.2 Interaction dans une page web - Utilisation de JavaScript

!!! note "Cours"
    **JavaScript** est le langage qui permet de rendre une page web
    **interactive** : réagir à un clic, modifier le contenu de la page,
    valider un formulaire, etc. Il s'exécute dans le navigateur.

!!! example "Exemple minimal"
    ```html
    <button onclick="direBonjour()">Cliquez ici</button>
    <p id="message"></p>

    <script>
      function direBonjour() {
        document.getElementById("message").textContent = "Bonjour !";
      }
    </script>
    ```

!!! tip "Le DOM"
    Le **DOM** (Document Object Model) représente la page HTML sous forme
    d'arbre d'éléments. JavaScript permet de le lire et de le modifier
    dynamiquement (`getElementById`, `querySelector`, ...).

## Activité

1. Créer une page avec un bouton qui, au clic, change la couleur de fond de
   la page.
2. Créer un champ de saisie et un bouton "Afficher" qui affiche le texte
   saisi dans un paragraphe.

## Exercices

1. Écrire une fonction JavaScript qui incrémente un compteur affiché à
   l'écran à chaque clic sur un bouton.

??? abstract "Correction"
    ```html
    <button onclick="compteur++; document.getElementById('c').textContent = compteur;">+1</button>
    <p id="c">0</p>
    <script>
      let compteur = 0;
    </script>
    ```
