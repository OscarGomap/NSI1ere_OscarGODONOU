# 1.1 Écriture d'un entier dans une base

!!! note "Cours"
    Un ordinateur ne manipule que des **0** et des **1** : c'est le système **binaire**
    (base 2). On utilise aussi souvent la base **hexadécimale** (base 16, chiffres
    0-9 puis A-F) pour écrire des octets de façon compacte.

    En base $b$, un nombre s'écrit $\overline{a_n a_{n-1} \dots a_1 a_0}$ et sa valeur
    décimale est :

    $$ a_n \times b^n + a_{n-1} \times b^{n-1} + \dots + a_1 \times b + a_0 $$

!!! example "Conversion binaire → décimal"
    $1011_2 = 1\times2^3 + 0\times2^2 + 1\times2^1 + 1\times2^0 = 8+0+2+1 = 11_{10}$

!!! example "Conversion décimal → binaire (divisions successives)"
    Pour convertir $13_{10}$ en binaire, on divise successivement par 2 et on lit
    les restes de bas en haut :

    ```
    13 ÷ 2 = 6 reste 1
     6 ÷ 2 = 3 reste 0
     3 ÷ 2 = 1 reste 1
     1 ÷ 2 = 0 reste 1
    ```

    On lit les restes du bas vers le haut : $13_{10} = 1101_2$

!!! tip "Astuce"
    En Python : `bin(13)` donne `'0b1101'` et `int('1101', 2)` redonne `13`.
    Pour l'hexadécimal : `hex(13)` donne `'0xd'` et `int('d', 16)` redonne `13`.

## Exercices

1. Écrire une fonction `decimal_vers_binaire(n)` qui renvoie l'écriture binaire
   (sous forme de chaîne de caractères) d'un entier positif `n`, sans utiliser `bin`.
2. Combien de valeurs différentes peut-on coder avec 8 bits ? Avec $n$ bits ?

??? abstract "Correction"
    ```python
    def decimal_vers_binaire(n):
        if n == 0:
            return "0"
        chiffres = ""
        while n > 0:
            chiffres = str(n % 2) + chiffres
            n = n // 2
        return chiffres
    ```
    Avec $n$ bits, on peut coder $2^n$ valeurs différentes (de 0 à $2^n - 1$),
    soit 256 valeurs avec 8 bits.
