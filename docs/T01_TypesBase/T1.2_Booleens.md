# 1.2 Valeurs booléennes

!!! note "Cours"
    Une **valeur booléenne** (type `bool` en Python) ne peut prendre que deux
    valeurs : `True` (vrai) ou `False` (faux). Les booléens sont au cœur des
    tests et des conditions.

    **Opérateurs de comparaison** : `==`, `!=`, `<`, `<=`, `>`, `>=`

    **Opérateurs logiques** : `and`, `or`, `not`

!!! example "Tables de vérité"
    | a | b | a and b | a or b |
    |---|---|---------|--------|
    | Vrai | Vrai | Vrai | Vrai |
    | Vrai | Faux | Faux | Vrai |
    | Faux | Vrai | Faux | Vrai |
    | Faux | Faux | Faux | Faux |

!!! example "En Python"
    ```python
    age = 17
    a_le_bac = False
    print(age >= 18)               # False
    print(age >= 15 and not a_le_bac)  # True
    ```

!!! warning "Attention"
    Ne confondez pas `=` (affectation) et `==` (test d'égalité) !

## Exercices

1. Écrire une fonction `est_annee_bissextile(annee)` qui renvoie `True` si
   l'année est bissextile (divisible par 4, sauf les multiples de 100 qui ne
   sont bissextiles que s'ils sont aussi multiples de 400).

??? abstract "Correction"
    ```python
    def est_annee_bissextile(annee):
        return annee % 4 == 0 and (annee % 100 != 0 or annee % 400 == 0)
    ```
