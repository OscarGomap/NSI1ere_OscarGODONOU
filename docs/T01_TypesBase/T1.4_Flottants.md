# 1.4 Flottants

!!! note "Cours"
    Les nombres réels sont représentés en machine par des **nombres à virgule
    flottante**, selon la norme **IEEE 754**. Un flottant s'écrit sous la forme :

    $$ (-1)^s \times 1{,}m \times 2^{e} $$

    avec un bit de signe $s$, une mantisse $m$ et un exposant $e$.

!!! warning "Attention : imprécision"
    Les flottants ne représentent pas exactement tous les nombres réels.

    ```python
    print(0.1 + 0.2)  # 0.30000000000000004
    ```

    Ce n'est pas un bug : certains nombres décimaux n'ont pas d'écriture finie
    en binaire (tout comme $1/3$ n'a pas d'écriture décimale finie).

!!! tip "Astuce"
    Pour comparer deux flottants, on évite `==` et on teste plutôt si leur
    différence est très petite :

    ```python
    abs(a - b) < 1e-9
    ```

## Activité

2. Proposer une fonction `presque_egaux(a, b)` qui teste si deux flottants
   sont "presque égaux".

## Exercices

1. Pourquoi ne faut-il jamais tester l'égalité stricte entre deux résultats
   de calculs flottants dans un programme ?

??? abstract "Correction"
    Parce que les erreurs d'arrondi liées à la représentation binaire des
    flottants peuvent rendre deux résultats mathématiquement égaux
    différents en machine (comme `0.1 + 0.2` qui n'est pas rigoureusement
    égal à `0.3`).
