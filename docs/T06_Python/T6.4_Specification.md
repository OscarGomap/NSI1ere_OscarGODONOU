# 6.4 Spécification

!!! note "Cours"
    **Spécifier** une fonction, c'est décrire précisément, avant même de
    l'écrire, ce qu'elle prend en paramètre, ce qu'elle renvoie et son
    comportement — souvent sous forme d'une **docstring** en Python.

    ```python
    def moyenne(liste):
        """
        Paramètre : liste (list de float ou int), non vide
        Renvoie : la moyenne (float) des éléments de la liste
        """
        return sum(liste) / len(liste)
    ```

!!! tip "Pourquoi spécifier ?"
    Cela permet de :

    - clarifier ce que doit faire la fonction avant de coder,
    - documenter le code pour d'autres personnes (ou soi-même plus tard),
    - anticiper les cas particuliers à gérer.

    ```python
    def inverser_chaine(s):
        """
        Paramètre : s (str)
        Renvoie : la chaîne s inversée (str)
        """
        return s[::-1]
    ```
