# 6.3 Tester une fonction

!!! note "Cours"
    **Tester** une fonction consiste à vérifier qu'elle produit le résultat
    attendu pour différentes entrées, y compris des **cas particuliers**
    (valeurs limites, cas vide, valeurs négatives...).

    L'instruction `assert` permet de vérifier automatiquement qu'une
    condition est vraie : si elle est fausse, le programme s'arrête avec une
    erreur.

!!! example "Utiliser assert"
    ```python
    def double(x):
        return x * 2

    assert double(3) == 6
    assert double(0) == 0
    assert double(-2) == -4
    print("Tous les tests sont passés !")
    ```

!!! tip "Bonnes pratiques"
    Pensez à tester :

    - un cas "normal",
    - un cas limite (0, liste vide, valeur maximale...),
    - un cas particulier (nombre négatif, chaîne vide...).

## Activité

1. Écrire trois tests `assert` pour la fonction `carre(x)` vue précédemment.
2. Écrire une fonction avec une erreur volontaire, puis observer le message
   renvoyé par `assert` lorsqu'un test échoue.

## Exercices

1. Écrire un jeu de tests complet (au moins 4 cas) pour une fonction
   `est_palindrome(mot)` qui renvoie `True` si le mot se lit de la même
   façon dans les deux sens.

??? abstract "Correction"
    ```python
    def est_palindrome(mot):
        return mot == mot[::-1]

    assert est_palindrome("radar") == True
    assert est_palindrome("nsi") == False
    assert est_palindrome("") == True
    assert est_palindrome("a") == True
    ```
