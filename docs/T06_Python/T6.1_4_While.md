# 6.1.4 La boucle while

!!! note "Cours"
    La boucle `while` répète un bloc d'instructions **tant qu'une condition
    est vraie**. Contrairement à `for`, on ne connaît pas forcément à
    l'avance le nombre d'itérations.

    ```python
    n = 0
    while n < 5:
        print(n)
        n = n + 1
    ```

!!! warning "Attention aux boucles infinies"
    Si la condition reste toujours vraie, la boucle ne s'arrête jamais !
    Vérifiez toujours qu'une variable de la condition évolue dans le corps
    de la boucle.

!!! example "Utilisation typique : attendre une saisie valide"
    ```python
    reponse = ""
    while reponse not in ("oui", "non"):
        reponse = input("Continuer ? (oui/non) : ")
    ```

## Exercices

1. Écrire une fonction `divise_par_2(n)` qui renvoie le nombre de fois où
   l'on peut diviser `n` par 2 (division entière) avant d'obtenir 0.

??? abstract "Correction"
    ```python
    def divise_par_2(n):
        compteur = 0
        while n > 0:
            n = n // 2
            compteur += 1
        return compteur
    ```
