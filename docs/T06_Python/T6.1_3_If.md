# 6.1.3 L'instruction conditionnelle if

!!! note "Cours"
    L'instruction `if` permet d'exécuter un bloc de code seulement si une
    condition est vraie.

    ```python
    note = 12
    if note >= 10:
        print("Admis")
    else:
        print("Non admis")
    ```

    Pour tester plusieurs cas, on utilise `elif` :

    ```python
    if note >= 16:
        print("Très bien")
    elif note >= 14:
        print("Bien")
    elif note >= 10:
        print("Passable")
    else:
        print("Insuffisant")
    ```

!!! warning "Attention à l'indentation"
    En Python, l'indentation (les espaces en début de ligne) délimite les
    blocs de code. Une erreur d'indentation provoque une erreur de syntaxe.
