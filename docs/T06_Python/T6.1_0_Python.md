# 6.1.0 Prise en main de Python

!!! note "Cours"
    Python est un langage de programmation interprété, simple à lire et très
    utilisé, aussi bien pour l'apprentissage que dans le monde professionnel
    (science des données, intelligence artificielle, développement web...).

## Installer et utiliser Python

!!! tip "Astuce"
    Vous pouvez utiliser Python directement en ligne, sans rien installer,
    avec des environnements comme [Basthon](https://console.basthon.fr/)
    ou [Capytale](https://capytale2.ac-paris.fr/).

## Premier programme

```python
print("Bonjour, bienvenue en NSI !")
```

!!! example "Exemple"
    ```python
    prenom = input("Quel est ton prénom ? ")
    print("Bonjour", prenom, "!")
    ```

## Exercices

1. Écrire un programme qui affiche votre prénom et votre âge.
2. Écrire un programme qui demande deux nombres à l'utilisateur et affiche
   leur somme.

??? abstract "Correction de l'exercice 2"
    ```python
    a = float(input("Premier nombre : "))
    b = float(input("Deuxième nombre : "))
    print("La somme est :", a + b)
    ```
