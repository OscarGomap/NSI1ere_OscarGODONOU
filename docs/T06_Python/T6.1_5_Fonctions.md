# 6.1.5 Les fonctions

!!! note "Cours"
    Une **fonction** regroupe un bloc d'instructions réutilisable. Elle peut
    recevoir des **paramètres** et renvoyer un **résultat** avec `return`.

    ```python
    def carre(x):
        return x * x

    resultat = carre(5)   # resultat vaut 25
    ```

!!! example "Fonction avec plusieurs paramètres"
    ```python
    def perimetre_rectangle(longueur, largeur):
        return 2 * (longueur + largeur)
    ```

!!! tip "Portée des variables"
    Une variable créée **à l'intérieur** d'une fonction (variable locale)
    n'existe pas en dehors de cette fonction.
