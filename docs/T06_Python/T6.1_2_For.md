# 6.1.2 La boucle for

!!! note "Cours"
    La boucle `for` permet de répéter des instructions pour chaque élément
    d'une séquence (liste, chaîne de caractères, plage de nombres...).

    ```python
    for i in range(5):
        print(i)   # affiche 0, 1, 2, 3, 4
    ```

!!! example "Parcourir une liste"
    ```python
    fruits = ["mangue", "ananas", "banane"]
    for fruit in fruits:
        print(fruit)
    ```

!!! tip "range() avec plusieurs arguments"
    - `range(5)` → 0, 1, 2, 3, 4
    - `range(2, 8)` → 2, 3, 4, 5, 6, 7
    - `range(0, 10, 2)` → 0, 2, 4, 6, 8 (pas de 2)
