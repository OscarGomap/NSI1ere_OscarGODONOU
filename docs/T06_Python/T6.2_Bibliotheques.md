# 6.2 Utilisation de bibliothèques

!!! note "Cours"
    Une **bibliothèque** (ou module) est un ensemble de fonctions déjà
    écrites, que l'on peut importer pour éviter de tout redévelopper
    soi-même.

    ```python
    import math
    print(math.sqrt(16))   # 4.0
    print(math.pi)          # 3.14159...

    from random import randint
    print(randint(1, 6))    # simule un dé à 6 faces
    ```

!!! example "Quelques bibliothèques utiles"
    | Bibliothèque | Rôle |
    |--------------|------|
    | `math` | Fonctions mathématiques |
    | `random` | Génération de nombres aléatoires |
    | `time` | Gestion du temps |
    | `turtle` | Dessin géométrique |

!!! tip "Astuce"
    On peut importer un module avec un alias pour raccourcir son nom :
    `import random as rd`.

## Exercices

1. Écrire une fonction `tirage_loto(n)` qui renvoie une liste de `n` nombres
   entiers aléatoires distincts entre 1 et 49.

??? abstract "Correction"
    ```python
    from random import randint

    def tirage_loto(n):
        numeros = []
        while len(numeros) < n:
            nombre = randint(1, 49)
            if nombre not in numeros:
                numeros.append(nombre)
        return numeros
    ```
