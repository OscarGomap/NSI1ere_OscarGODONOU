# 6.1.1 Les variables

!!! note "Cours"
    Une **variable** est un espace mémoire nommé dans lequel on stocke une
    valeur. En Python, on l'affecte avec le signe `=` :

    ```python
    age = 16
    prenom = "Sika"
    moyenne = 14.5
    ```

    Une variable a un **type** (`int`, `float`, `str`, `bool`...), déterminé
    automatiquement par Python selon la valeur affectée.

!!! example "Changer de valeur"
    ```python
    x = 5
    x = x + 1   # x vaut maintenant 6
    x += 1      # x vaut maintenant 7 (équivalent à x = x + 1)
    ```

!!! warning "Attention"
    Le nom d'une variable ne peut pas commencer par un chiffre, ne doit pas
    contenir d'espace ni d'accent, et est sensible à la casse
    (`age` et `Age` sont deux variables différentes).
