# T2.1 Tableaux et listes

!!! note "Cours"
    En Python, une **liste** est une structure de données qui permet de stocker
    une collection ordonnée et modifiable de valeurs.

    ```python
    notes = [12, 15, 9, 18, 14]
    ```

    - L'accès à un élément se fait par son **indice**, en commençant à 0.
    - Les listes sont **mutables** : on peut modifier, ajouter ou supprimer des éléments.

!!! example "Exemple"
    ```python
    notes = [12, 15, 9, 18, 14]
    print(notes[0])       # 12 (premier élément)
    print(notes[-1])      # 14 (dernier élément)
    notes.append(16)      # ajoute 16 à la fin
    print(len(notes))     # nombre d'éléments
    ```

!!! tip "Astuce"
    On peut parcourir une liste avec une boucle `for` :

    ```python
    for note in notes:
        print(note)
    ```

## Exercices

=== "Énoncé"

    Écrire une fonction `moyenne(liste)` qui renvoie la moyenne des éléments
    d'une liste de nombres.

=== "Solution"

    ```python
    def moyenne(liste):
        return sum(liste) / len(liste)
    ```

!!! warning "Attention"
    Une division par zéro se produit si la liste est vide : pensez à gérer ce cas
    particulier dans vos fonctions.
