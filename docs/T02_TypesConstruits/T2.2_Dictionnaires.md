# 2.2 Dictionnaires

!!! note "Cours"
    Un **dictionnaire** (`dict`) associe des **clés** à des **valeurs**. Contrairement
    aux listes, l'accès se fait par clé et non par indice numérique.

    ```python
    eleve = {"nom": "Godonou", "prenom": "Oscar", "note": 15}
    ```

!!! example "Manipulations de base"
    ```python
    print(eleve["prenom"])       # Oscar
    eleve["note"] = 17           # modifier une valeur
    eleve["classe"] = "1NSI"     # ajouter une clé
    print(eleve.keys())          # toutes les clés
    print(eleve.values())        # toutes les valeurs
    del eleve["classe"]          # supprimer une clé
    ```

!!! tip "Astuce"
    Parcourir un dictionnaire :

    ```python
    for cle, valeur in eleve.items():
        print(cle, "->", valeur)
    ```

!!! warning "Attention"
    Les clés d'un dictionnaire doivent être uniques et non modifiables
    (nombres, chaînes de caractères, tuples...), mais pas des listes.

## Exercices

1. Écrire une fonction `compter_lettres(mot)` qui renvoie un dictionnaire
   associant chaque lettre du mot à son nombre d'occurrences.

??? abstract "Correction"
    ```python
    def compter_lettres(mot):
        compteur = {}
        for lettre in mot:
            if lettre in compteur:
                compteur[lettre] += 1
            else:
                compteur[lettre] = 1
        return compteur
    ```
