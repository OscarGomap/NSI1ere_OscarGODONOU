# 3.1 Tables de données

!!! note "Cours"
    Une **table de données** rassemble des enregistrements ayant les mêmes
    caractéristiques (colonnes), un peu comme une feuille de tableur. En
    Python, on la représente souvent par une **liste de dictionnaires**.

    ```python
    eleves = [
        {"nom": "Alassane", "note": 14},
        {"nom": "Bio", "note": 8},
        {"nom": "Carine", "note": 17},
    ]
    ```

!!! example "Rechercher dans une table"
    ```python
    def trouver(table, nom_cherche):
        for enregistrement in table:
            if enregistrement["nom"] == nom_cherche:
                return enregistrement
        return None
    ```

!!! tip "Astuce"
    Pour filtrer une table (par exemple les élèves ayant plus de 10 de
    moyenne), on utilise une **liste en compréhension** :

    ```python
    admis = [e for e in eleves if e["note"] >= 10]
    ```

## Activité

2. Écrire une fonction qui renvoie la liste des noms des élèves ayant une

## Exercices

1. Écrire une fonction `note_max(table)` qui renvoie l'enregistrement de
   l'élève ayant la meilleure note.

??? abstract "Correction"
    ```python
    def note_max(table):
        meilleur = table[0]
        for enregistrement in table:
            if enregistrement["note"] > meilleur["note"]:
                meilleur = enregistrement
        return meilleur
    ```
