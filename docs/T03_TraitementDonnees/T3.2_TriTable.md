# 3.2 Opérations sur les tables

!!! note "Cours"
    Trier une table consiste à réordonner ses enregistrements selon la valeur
    d'un champ (une colonne). En Python, `sorted()` accepte un argument
    `key` pour préciser selon quel critère trier.

!!! example "Trier une table"
    ```python
    eleves = [
        {"nom": "Alassane", "note": 14},
        {"nom": "Bio", "note": 8},
        {"nom": "Carine", "note": 17},
    ]

    tri_par_note = sorted(eleves, key=lambda e: e["note"])
    tri_par_note_desc = sorted(eleves, key=lambda e: e["note"], reverse=True)
    ```

!!! tip "Astuce"
    On peut aussi trier selon plusieurs critères en renvoyant un tuple dans
    la fonction `key` : `key=lambda e: (e["classe"], -e["note"])`.

## Activité

2. Trier la table par note décroissante, puis afficher uniquement le nom du
   premier élève.

## Exercices

1. Écrire, **sans utiliser `sorted`**, une fonction `tri_par_note(table)` qui
   trie une table par tri par sélection selon le champ `"note"`.

??? abstract "Correction"
    ```python
    def tri_par_note(table):
        table = table.copy()
        for i in range(len(table)):
            indice_min = i
            for j in range(i + 1, len(table)):
                if table[j]["note"] < table[indice_min]["note"]:
                    indice_min = j
            table[i], table[indice_min] = table[indice_min], table[i]
        return table
    ```
