# 3.3 Fusion (par jointure) de tables

!!! note "Cours"
    La **jointure** consiste à combiner deux tables à partir d'un champ
    commun (une clé). C'est une opération fondamentale des bases de données
    relationnelles.

!!! example "Deux tables à joindre"
    ```python
    eleves = [
        {"id": 1, "nom": "Alassane"},
        {"id": 2, "nom": "Bio"},
    ]
    notes = [
        {"id_eleve": 1, "matiere": "NSI", "note": 14},
        {"id_eleve": 2, "matiere": "NSI", "note": 8},
        {"id_eleve": 1, "matiere": "Maths", "note": 16},
    ]
    ```

!!! example "Réaliser la jointure"
    ```python
    def jointure(eleves, notes):
        resultat = []
        for note in notes:
            for eleve in eleves:
                if eleve["id"] == note["id_eleve"]:
                    resultat.append({
                        "nom": eleve["nom"],
                        "matiere": note["matiere"],
                        "note": note["note"],
                    })
        return resultat
    ```

## Activité

1. Exécuter la fonction `jointure` sur les tables ci-dessus et afficher le
   résultat.
2. Modifier la fonction pour ne garder que les notes de NSI.

## Exercices

1. Quelle est la complexité (en nombre d'itérations) de cette jointure
   "naïve" en fonction du nombre d'éléments `n` de `eleves` et `m` de `notes` ?

??? abstract "Correction"
    La complexité est en $O(n \times m)$ : pour chaque élément de `notes`,
    on parcourt potentiellement toute la table `eleves`.
